# Sistema para Clínicas Médicas (CRM + Prontuário + Financeiro)

Este repositório descreve a proposta de um sistema integrado para clínicas médicas, unindo CRM, prontuário médico e financeiro em uma única plataforma. O objetivo é centralizar dados clínicos e administrativos para melhorar a jornada do paciente e a gestão do negócio.

## Objetivos principais

- **Unificar dados**: cadastro único de pacientes e profissionais para todo o sistema.
- **Organizar atendimento**: agenda, histórico clínico e evolução do paciente em um só lugar.
- **Controlar receitas e despesas**: faturamento, repasses e conciliação financeira integrada.

## Visão geral dos módulos

- **CRM**: captação de pacientes, funil de atendimento, campanhas e relacionamento.
- **Prontuário**: histórico clínico, anamnese, prescrições, anexos e evolução.
- **Financeiro**: contas a pagar/receber, faturamento, repasses e relatórios.

Para detalhes completos, consulte a documentação em `docs/`.
